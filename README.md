# EditKit

프리미어 프로 편집 도우미 패널 — 자동 자막(받아쓰기 + 말소리에 맞춘 시간), 모션 자막, 화자 나누기, 자료 찾기, 공백 컷.

## 설치
1. [Releases](../../releases/latest)에서 `EditKit-<버전>-setup.zip`을 받아 압축을 풀어요.
2. `EditKit 설치.bat`을 더블클릭해요.
3. 프리미어 프로 → 창 → 확장 → EditKit.
4. 처음 열면 [설치하기] — 필요한 프로그램과 모델을 EditKit 폴더 안에 받아요 (한 번만).

필요: Windows 10/11 64비트, Premiere Pro 2022 이상, NVIDIA 그래픽카드 권장.
